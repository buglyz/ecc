# 纯 Go + Win32 + GDI 原生桌面 UI 重构（2026-08-19）

## 目标

- 彻底移除 `github.com/jchv/go-webview2` 及相关依赖，消除所有 WebView2 子进程与多余内存开销。
- 采用纯 Go + Win32 API + GDI 双缓冲自绘实现原生桌面 UI。
- 参考视觉图设计，构建深色、紧凑、专业的硬件控制台 UI。
- 绝对禁止修改核心控制目录：`internal/controller/`、`internal/ec/`、`internal/sensors/`。
- 每个 Go 文件不超过 400 行，模块清晰拆分。
