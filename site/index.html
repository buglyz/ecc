ECC Fan Controller

通过 EC（Embedded Controller）寄存器控制笔记本风扇的 Windows 工具。读取 CPU/GPU 温度，按自定义曲线写入风扇转速，自带一个本地 Web 控制台。

Windows 10/11 x64 · 管理员权限 · 主程序 MIT · v1.1.0

下载 源码 工作原理 安全审计

概览

自定义曲线
5 个温度节点。画布拖拽或表格精确输入，两种方式实时同步。
实时监控
CPU/GPU 温度、目标温度、风扇输出与实际 RPM；历史窗口 1–480 分钟。
温度策略
加权（0.7·CPU + 0.3·GPU）、取最大值、仅 CPU、仅 GPU。
预设与手动
静音、平衡、性能三挡；手动模式锁定 0–100% 固定转速。
托盘与自启
动态托盘图标。Program Files 安装使用 HIGHEST 任务，登录免 UAC；其他目录使用 LIMITED 任务，登录时请求一次 UAC。
安全兜底
首个有效温度前不接管 EC；连续 3 个周期无有效温度时释放控制权；写入失败触发托盘告警。
本地优先
控制台只监听 127.0.0.1，写接口校验会话令牌与 Host；无账号、无遥测。
单实例
全局命名互斥体，与端口无关。重复启动只会打开已有控制台。

工作原理

默认每 1 秒采样一次，6 次采样为一个决策周期。程序不直接读硬件传感器，而是通过一个常驻 PowerShell 进程桥接 LibreHardwareMonitor。

  1. 读取温度

    PowerShell 进程加载 LibreHardwareMonitor，返回 CPU/GPU 温度；子进程异常时按 1s → 2s → 4s…（上限 30s）退避重启。

  2. 合并目标温度

    按当前策略把两路温度合成一个值，避免单路传感器噪声直接驱动风扇。

  3. 曲线插值

    在 5 点曲线上线性插值出目标转速；2°C 滞回与 30 秒心跳减少不必要的 EC 写入。

  4. 写入 EC

    通过 ec-probe 写风扇寄存器，并读取 RPM 寄存器获取实际转速。

用途寄存器说明
Fan 1 / Fan 20x2C / 0x2D写入 0–100（0x00–0x64）；0xFF 释放给固件
Fan 1 RPM0xB0 / 0xB1小端 16 位，低字节在前
Fan 2 RPM0xB2 / 0xB3小端 16 位，低字节在前

安全策略：自动模式在拿到首个有效温度前保持固件控制。连续 3 个周期没有任何有效温度时，写入 0xFF 释放 EC 并触发托盘告警；温度恢复后自动重新接管。写失败不会记为“已提交”，下个周期会重试。

安装

从 Releases 下载最新版本。安装包会请求管理员权限，默认安装到 Program Files\ECC，并创建桌面/开始菜单快捷方式。

安装包  ECC-Setup-<version>.exe
便携版  ecc-<version>-windows-amd64.zip
校验    SHA256SUMS.txt

便携版解压后运行 install.ps1，或直接双击 ecc.exe（需保留同目录 assets/）。启动后浏览器打开 http://127.0.0.1:8765。

卸载：安装包版本在 Windows「设置 → 应用」中卸载；便携版运行 uninstall.ps1。

硬件兼容性

EC 寄存器地址因机型而异。本项目只在目标机型上验证了风扇寄存器 0x2C/0x2D 和 RPM 寄存器 0xB0–0xB3。其他机型可能无效，甚至误触其他 EC 功能。

未知机型请先用 --dry-run 或 --simulate，并在管理员 PowerShell 中执行 ec-probe read 0x2C 回读确认。完整探测方法见 README。

安全与发布

配置写入采用临时文件 + 原子替换，损坏时自动备份为 .corrupted.<timestamp>。控制台只监听 127.0.0.1，所有写接口校验页面注入的会话令牌和回环 Host。程序不收集遥测，配置与日志位于 %LOCALAPPDATA%\FanController。

主程序使用 MIT 许可证，第三方组件遵循各自许可证。每个 Release 附带 SHA256SUMS.txt。当前安装包尚未代码签名，正在申请 SignPath Foundation 的免费开源签名；在此之前首次运行可能出现 SmartScreen 提示。

常见问题

会把温度数据上传到云端吗？
不会。温度、转速和配置只在本机处理，没有账号体系，也没有遥测。
为什么需要管理员权限？
访问 EC 寄存器需要加载 WinRing0 驱动，由 ec-probe.exe 完成读写；没有管理员权限无法操作硬件。
自定义目录安装后，开机自启会弹 UAC 吗？
会，登录时请求一次。Program Files 内使用 HIGHEST 计划任务，登录免 UAC；其他目录使用 LIMITED 任务，由程序自身请求提权。
换一台笔记本能用吗？
不一定。风扇和 RPM 寄存器地址因机型而异，先确认寄存器，再用 --dry-run / --simulate 验证。
安装包会触发 SmartScreen 吗？
当前发布包未签名，首次运行可能出现提示。可以用 SHA256SUMS.txt 校验文件完整性；SignPath Foundation 签名正在申请中。
